Read a message

#

Activate the message row to mark it read. Activate it again to return it to Unread.

import 'package:flutter/widgets.dart';
import 'package:ledger_ui/ledger_ui.dart';

class ReadMessage extends StatefulWidget {
  const ReadMessage({super.key});
  @override
  State<ReadMessage> createState() => _ReadMessageState();
}

class _ReadMessageState extends State<ReadMessage> {
  bool read = false;
  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 440),
    child: LedgerRow(
      title: 'Route change',
      subtitle: read ? 'Read' : 'Unread',
      onTap: () => setState(() => read = !read),
    ),
  );
}

Parameters

LedgerRow API ↗
title
The row's words, joined to its value by the dot leader.
leading
A mark before the words (a glyph, a monogram).
value
The value at the line's end, on the leader (a LedgerAmount).
subtitle
The sub line's start words.
trailingSubtitle
The sub line's end words.
subtitleMonospace
The start words in the mono (an account's kind and mask).
subtitleTone
The ink of the sub line's start words.
trailingSubtitleTone
The ink of the sub line's end words.
tag
A tag after the title (Pending).
trailing
A mark at the row's end (a chevron, a switch).
onTap
Makes the whole row one link.
semanticLabel
What a screen reader says when the row's words say too little.
focusNode
Supplies a focus node owned and disposed by the caller.
