Neumorphism

Explore the controls in Neumorphism and the Dart code behind them.

Try Stint →Package on pub.dev ↗Source on GitHub ↗

Theme

Palettes

Six palettes, each by day and by night: NeumorphicThemeData.palettes, each a RawNamedPalette with an id to store and a label to show. NeumorphicThemeData.preset(id, brightness) builds a stored id’s theme again.

  • Porcelain
  • Pompeii
  • Verona
  • Siena
  • Tyrian
  • Capri

Corners

shapeScheme sets the corners and the depth. No corner is sharp: the smallest is 6, and a face inside another follows the outer corner.

import 'package:material_ui/material_ui.dart';
import 'package:neumorphism_ui/neumorphism_ui.dart';

final theme = NeumorphicThemeData.porcelain().copyWith(
  density: NeumorphicDensity.compact,
  shapeScheme: NeumorphicThemeData.defaultShapeScheme.copyWith(depth: .5),
);

final custom = NeumorphicThemeData.from(
  ground: const Color(0xFFE9E4DD),
  pigment: const Color(0xFF315B83),
  brightness: Brightness.light,
);

Sheets on the bar

On ui_core 0.8.7 or later, a bottom sheet opened over the app shell’s places stands on the shell’s bar: the bar stays in view under the barrier, and a tap on it closes the sheet. A full-screen sheet and a dialog still cover the whole screen. Bottom sheet in Neumorphism
