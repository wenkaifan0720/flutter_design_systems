Theme

Palettes

Six palettes, each by day and by night: ClayThemeData.palettes, each a RawNamedPalette with an id to store and a label to show. ClayThemeData.preset(id, brightness) builds a stored id’s theme again.

  • Mint

Corners

shapeScheme is the one source of Clay's corners and relief: steps of 6, 9, 16, 24 and 32, each held to Clay's band, and a depth that scales how far a part stands. A part takes one step on every corner from its style's corners; balls, pills and the dock's places stay round.

import 'package:clay_ui/clay_ui.dart';
import 'package:material_ui/material_ui.dart';

// A firmer clay: tighter corners, shallower relief.
ClayThemeData firm(Brightness brightness) {
  final theme = ClayThemeData.clay(brightness);
  final shapes = theme.shapeScheme;
  return theme.copyWith(
    shapeScheme: shapes.copyWith(
      corners: shapes.corners.copyWith(small: 7, medium: 12, large: 18, extraLarge: 24),
      depth: 0.75,
    ),
  );
}

Widget host(BuildContext context, Widget? child) =>
    ClayHost(theme: firm(Brightness.light), darkTheme: firm(Brightness.dark), child: child!);

Sheets on the bar

On ui_core 0.8.7 or later, a bottom sheet opened over the app shell’s places stands on the shell’s bar: the bar stays in view under the barrier, and a tap on it closes the sheet. A full-screen sheet and a dialog still cover the whole screen. Bottom sheet in Clay
