Retro Desktop

Explore the controls in Retro Desktop and the Dart code behind them.

Try Stint →Package on pub.dev ↗Source on GitHub ↗

Theme

Palettes

Six palettes, each by day and by night: RetroDesktopThemeData.palettes, each a RawNamedPalette with an id to store and a label to show. RetroDesktopThemeData.preset(id, brightness) builds a stored id’s theme again.

  • Classic
  • Lagoon
  • Berry
  • Marmalade
  • Slate
  • Lime

Corners

Corners, line widths and shadows belong to the appearance and are not settings: Retro Desktop opens none of ui_core's RawShapeScheme. One appearance rounds push buttons, popups and tabs by 4; the other is square everywhere.

Sheets on the bar

On ui_core 0.8.7 or later, a bottom sheet opened over the app shell’s places stands on the shell’s bar: the bar stays in view under the barrier, and a tap on it closes the sheet. A full-screen sheet and a dialog still cover the whole screen. Bottom sheet in Retro Desktop
