Keycap

Explore the controls in Keycap and the Dart code behind them.

Try Stint →Package on pub.dev ↗Source on GitHub ↗

Theme

Palettes

Six palettes, each by day and by night: KeycapThemeData.palettes, each a RawNamedPalette with an id to store and a label to show. KeycapThemeData.preset(id, brightness) builds a stored id’s theme again.

  • Classic
  • Retro
  • Sage
  • Rose
  • Lilac
  • Ocean

Corners

A part's corners are fixed (ui_core's cornerFreedom: fixed): a keycap's profile is the look, so a style's corners leaves them as they are.

Sheets on the bar

On ui_core 0.8.7 or later, a bottom sheet opened over the app shell’s places stands on the shell’s bar: the bar stays in view under the barrier, and a tap on it closes the sheet. A full-screen sheet and a dialog still cover the whole screen. Bottom sheet in Keycap
