Compare daily balances

#

Compare the balance over the first four days of January and February. January dips on day three, while February rises each day.

Tab reaches the chart; the arrow keys step from point to point, and each is read with its day and value. The table under it gives every value.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class CompareBalances extends StatefulWidget {
  const CompareBalances({super.key});
  @override
  State<CompareBalances> createState() => _CompareBalancesState();
}

class _CompareBalancesState extends State<CompareBalances> {
  bool alternate = false;

  @override
  Widget build(BuildContext context) => SingleChildScrollView(
    child: ConstrainedBox(
      constraints: const BoxConstraints(maxWidth: 420),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.stretch,
        spacing: 16,
        children: [
          CivicSegmentedControl<bool>(
            labelText: 'Show',
            segments: const [
              CivicSegment(value: false, label: 'January'),
              CivicSegment(value: true, label: 'February'),
            ],
            value: alternate,
            onChanged: (next) => setState(() => alternate = next),
          ),
          CivicLineChart(
            height: 180,
            title: 'Daily balance, ${alternate ? 'February' : 'January'}',
            labelHeader: 'Day',
            labels: const ['Day 1', 'Day 2', 'Day 3', 'Day 4'],
            series: [
              CivicChartSeries(
                'Total',
                alternate ? const [86, 92, 98, 112] : const [90, 100, 94, 106],
              ),
            ],
          ),
        ],
      ),
    ),
  );
}

Parameters

CivicLineChart API ↗
title
Names the chart, as its heading and its table’s caption.
labels
The point names along the foot, in order.
series
Each line’s name and its values; a null value is a gap.
summary
What the chart shows, in words, over it.
labelHeader
Names the table’s first column.
missingLabel
Says a missing value in the table and the card.
