Choose a sort order

#

Open Sort files and choose Date. The current order appears below the trigger. Reopen the menu and choose Name to switch back.

components/menu/cupertino/sort_files.dart
import 'package:cupertino_ui/cupertino_ui.dart';

class SortFiles extends StatefulWidget {
  const SortFiles({super.key});
  @override
  State<SortFiles> createState() => _SortFilesState();
}

class _SortFilesState extends State<SortFiles> {
  String order = 'Name';

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      CupertinoMenuAnchor(
        builder: (context, controller, child) => CupertinoButton(
          onPressed: () =>
              controller.isOpen ? controller.close() : controller.open(),
          child: const Text('Sort files'),
        ),
        menuChildren: [
          for (final sort in ['Name', 'Date'])
            CupertinoMenuItem(
              leading: order == sort
                  ? const Icon(CupertinoIcons.check_mark)
                  : null,
              onPressed: () => setState(() => order = sort),
              child: Text(sort),
            ),
        ],
      ),
      const SizedBox(height: 12),
      Text('Sort order: $order'),
    ],
  );
}

Parameters

CupertinoMenuAnchor API ↗
menuChildren
The entries, usually CupertinoMenuItem widgets.
builder
Builds the button that opens the menu, given its MenuController.
controller
Opens and closes the menu from code.
enableLongPressToOpen
Whether a long press on the button opens the menu.
onOpen
Called when the menu opens.
onClose
Called when the menu closes.
