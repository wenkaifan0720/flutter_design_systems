Order the stops

#

Move Park below Market, then move it back. A row labelled Make first can also be activated to bring that stop to the top.

components/reorderable-list/material/order_stops.dart
import 'package:material_ui/material_ui.dart';

class OrderStops extends StatefulWidget {
  const OrderStops({super.key});
  @override
  State<OrderStops> createState() => _OrderStopsState();
}

class _OrderStopsState extends State<OrderStops> {
  final stops = ['Park', 'Market', 'Pier'];

  void move(int from, int to) {
    setState(() => stops.insert(to, stops.removeAt(from)));
  }

  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 440),
    child: SizedBox(
      height: 200,
      child: ReorderableListView(
        onReorderItem: move,
        children: [
          for (final (index, stop) in stops.indexed)
            ListTile(
              key: ValueKey(stop),
              title: Text(stop),
              subtitle: const Text('Make first'),
              onTap: () => move(index, 0),
            ),
        ],
      ),
    ),
  );
}

ReorderableListView API ↗
children
The rows, each with its own key.

Called with the old and new index of a moved row.

Whether each row gets a drag handle, or a long press on a phone.

A widget above the rows that does not move.

Decorates the row while it is being dragged.
