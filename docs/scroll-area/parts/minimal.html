Browse the stops

#

Scroll from Stop 1 to Stop 12 and back. The surrounding page stays in place while the stops move.

import 'package:flutter/widgets.dart';
import 'package:minimal_ui/minimal_ui.dart';

class BrowseStops extends StatelessWidget {
  const BrowseStops({super.key});
  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 440),
    child: MinimalScrollArea(
      height: 150,
      label: 'Route stops',
      alwaysShown: true,
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          for (var stop = 1; stop <= 12; stop++)
            Padding(
              padding: const EdgeInsets.symmetric(vertical: 8),
              child: Text('Stop $stop'),
            ),
        ],
      ),
    ),
  );
}

Parameters

MinimalScrollArea API ↗
child
The content.
controller
The scroll position, when the caller holds it.
axis
Which way it scrolls.
height
Its height, for a vertical area in a page that scrolls itself.
width
Its width, for a sideways area in a row.
alwaysShown
Show the scrollbar whenever there is anything to scroll.
label
What a screen reader calls the region.
shape
Chooses the outline of the component.
padding
Space round the content, inside the scrolling.
focusNode
The area's keyboard stop (the arrow and page keys scroll it).
autofocus
Whether it takes focus when it first shows.
