Read a delivery note

#

Open Delivery note to read where the parcel will be left. Close the sheet to return to the page.

import 'package:flutter/widgets.dart';
import 'package:ledger_ui/ledger_ui.dart';

class ReadDeliveryNote extends StatelessWidget {
  const ReadDeliveryNote({super.key});

  @override
  Widget build(BuildContext context) => LedgerButton(
    'Delivery note',
    onPressed: () => LedgerSheet.show<void>(
      context,
      title: 'Delivery note',
      builder: (_) => [const Text('Leave the parcel at the side door.')],
    ),
  );
}

Parameters

LedgerSheet API ↗
title
Heading at the top of the panel.
builder
Builds the content inside the sheet.
close
Shows the close button in the heading.
foot
Builds actions below the scrolling body.
