Flutter Design Systems

Sixteen design systems for Flutter, one package per look, all built on one foundation, ui_core. Each works under a MaterialApp, CupertinoApp or WidgetsApp, on phones and desktops, by day and by night.

  1. Pick a look

  2. Add its package

    flutter pub add minimal_ui

  3. Build with its widgets

    Wrap your app in the look’s theme as its README shows, then use its components:

    import 'package:flutter/widgets.dart';
import 'package:appliance_ui/appliance_ui.dart';

void main() => runApp(
  WidgetsApp(
    color: const Color(0xFFEE6A26),
    builder: (context, _) => ApplianceHost(
      child: Center(child: ApplianceButton.filled('Start', onPressed: () {})),
    ),
  ),
);
