Save a draft

#

Save the draft, then reset the example to try the action again.

Flutter preview Open preview ↗
components/button/studio/save_draft.dart
import 'package:flutter/widgets.dart';
import 'package:studio_ui/studio_ui.dart';

class SaveDraft extends StatefulWidget {
  const SaveDraft({super.key});
  @override
  State<SaveDraft> createState() => _SaveDraftState();
}

class _SaveDraftState extends State<SaveDraft> {
  bool saved = false;

  @override
  Widget build(BuildContext context) => Wrap(
    alignment: WrapAlignment.center,
    spacing: 12,
    runSpacing: 12,
    children: [
      StudioButton.lit(
        saved ? 'Draft saved' : 'Save draft',
        onPressed: saved ? null : () => setState(() => saved = true),
      ),
      StudioButton(
        'Reset',
        onPressed: saved ? () => setState(() => saved = false) : null,
      ),
    ],
  );
}

Supplies the FocusNode owned by the caller.
autofocus
Requests keyboard focus when the control first appears.

Shared behaviour

  • Keyboard and focus. Tab moves focus to an enabled button. Enter or Space activates it. A disabled action leaves the focus order.
  • Screen readers. The button exposes its label, role and enabled state. The visible label changes when the draft is saved.
  • Direction and type. The actions follow reading order in RTL. At larger text sizes they can wrap onto separate lines.
