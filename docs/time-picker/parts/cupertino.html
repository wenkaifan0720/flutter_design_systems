Set a reminder time

#

Move the reminder from 09:30 to another time. Some looks present the hour and minute inline, while others open a picker from the displayed time.

import 'package:cupertino_ui/cupertino_ui.dart';

class SetReminder extends StatefulWidget {
  const SetReminder({super.key});
  @override
  State<SetReminder> createState() => _SetReminderState();
}

class _SetReminderState extends State<SetReminder> {
  var reminder = DateTime(2026, 11, 12, 9, 30);

  void showPicker(Widget picker) => showCupertinoModalPopup<void>(
    context: context,
    builder: (context) => Container(
      height: 216,
      padding: const EdgeInsets.only(top: 6),
      color: CupertinoColors.systemBackground.resolveFrom(context),
      child: SafeArea(top: false, child: picker),
    ),
  );

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      CupertinoButton(
        onPressed: () => showPicker(
          CupertinoDatePicker(
            mode: CupertinoDatePickerMode.time,
            use24hFormat: true,
            initialDateTime: reminder,
            onDateTimeChanged: (next) => setState(() => reminder = next),
          ),
        ),
        child: const Text('Set reminder time'),
      ),
      const SizedBox(height: 12),
      Text(
        "Reminder: ${reminder.hour.toString().padLeft(2, '0')}:${reminder.minute.toString().padLeft(2, '0')}",
      ),
    ],
  );
}

Parameters

CupertinoDatePicker API ↗
mode
CupertinoDatePickerMode.time shows only the hour and minute wheels.
initialDateTime
The time shown when the wheels are first built.
onDateTimeChanged
Called with the time as the wheels settle.
use24hFormat
Whether the hours run from 0 to 23 with no AM or PM wheel.
minuteInterval
The step between the minutes on the wheel.
