Name a project

#

Type a one-letter project name to see the validation message. Add a second letter to clear it.

components/form-field/cupertino/name_project.dart
import 'package:cupertino_ui/cupertino_ui.dart';

class NameProject extends StatelessWidget {
  const NameProject({super.key});

  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 400),
    child: SingleChildScrollView(
      child: CupertinoFormSection.insetGrouped(
        header: const Text('Project'),
        footer: const Text('For example, Field notes.'),
        children: [
          CupertinoTextFormFieldRow(
            prefix: const Text('Name'),
            placeholder: 'Project name',
            autovalidateMode: AutovalidateMode.onUserInteraction,
            validator: (value) =>
                value?.trim().length == 1 ? 'Use at least two letters.' : null,
          ),
        ],
      ),
    ),
  );
}

Parameters

CupertinoTextFormFieldRow API ↗
validator
Returns the error for the current text, or null when it is valid; it shows under the row.
autovalidateMode
When the row checks itself: on each edit after the first, or only when its Form asks.
prefix
The row's label, before the input.
placeholder
The words shown while the row is empty.
onSaved
Called with the text when the enclosing Form saves.
