Browse the rooms

#

Move from the Hall to the Studio, then return. Try the carousel’s navigation as well as dragging the slides.

The Previous and Next buttons under the slides move one at a time, so no one has to drag.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class BrowseRooms extends StatefulWidget {
  const BrowseRooms({super.key});
  @override
  State<BrowseRooms> createState() => _BrowseRoomsState();
}

class _BrowseRoomsState extends State<BrowseRooms> {
  static const rooms = ['Hall', 'Studio', 'Loft'];
  int room = 0;

  @override
  Widget build(BuildContext context) => SingleChildScrollView(
    child: Column(
      mainAxisSize: MainAxisSize.min,
      crossAxisAlignment: CrossAxisAlignment.stretch,
      spacing: 12,
      children: [
        CivicCarousel(
          semanticLabel: 'Rooms',
          height: 140,
          itemCount: rooms.length,
          onPageChanged: (index) => setState(() => room = index),
          itemBuilder: (context, index) => ColoredBox(
            color: context.civicTheme.surface,
            child: Center(
              child: Text(rooms[index], style: context.civicText.headingM),
            ),
          ),
        ),
        Text('Room ${room + 1} of ${rooms.length}: ${rooms[room]}'),
      ],
    ),
  );
}

Parameters

CivicCarousel API ↗
itemCount
How many slides there are.
itemBuilder
Builds each slide.
semanticLabel
Names the set of slides for a screen reader.
height
The slides’ height.
onPageChanged
Receives the slide now in sight.
previousLabel
Words on the previous button.
nextLabel
Words on the next button.
