Choose a quantity

#

Start with two copies. Add a copy, then lower the count to one and try to decrease it again.

Type the number, or use the up and down arrows while the box has the focus.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class CountCopies extends StatefulWidget {
  const CountCopies({super.key});
  @override
  State<CountCopies> createState() => _CountCopiesState();
}

class _CountCopiesState extends State<CountCopies> {
  double? copies = 2;

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    crossAxisAlignment: CrossAxisAlignment.stretch,
    spacing: 16,
    children: [
      CivicNumberField(
        labelText: 'Copies',
        value: copies,
        min: 1,
        max: 10,
        onChanged: (next) => setState(() => copies = next),
      ),
      Text(copies == null ? 'No copies' : 'Copies: ${copies!.round()}'),
    ],
  );
}

Parameters

CivicNumberField API ↗

The number; null while the box is empty.

Receives the number typed or stepped.

The least it can be.
max
The most it can be.
step
How far the buttons and the arrow keys move it.
labelText
Asks for the number.
