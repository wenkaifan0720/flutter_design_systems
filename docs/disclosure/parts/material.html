Read pickup instructions

#

Open Pickup instructions to find the collection point. Close the section and the instructions disappear.

components/disclosure/material/read_pickup.dart
import 'package:material_ui/material_ui.dart';

class ReadPickup extends StatelessWidget {
  const ReadPickup({super.key});

  @override
  Widget build(BuildContext context) => const SizedBox(
    width: 440,
    child: SingleChildScrollView(
      child: ExpansionTile(
        title: Text('Pickup instructions'),
        expandedAlignment: AlignmentDirectional.centerStart,
        childrenPadding: EdgeInsets.fromLTRB(16, 0, 16, 16),
        children: [Text('Collect your parcel at the front desk.')],
      ),
    ),
  );
}

Parameters

ExpansionTile API ↗
title
The row's heading; a tap on it opens and closes the section.
children
The content shown while it is open.
initiallyExpanded
Whether it starts open.
onExpansionChanged
Called with whether it is now open.
controller
Opens and closes it from code.
childrenPadding
The space around the content.
