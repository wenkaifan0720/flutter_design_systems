Read pickup instructions

#

Open Pickup instructions to find the collection point. Close the section and the instructions disappear.

import 'package:flutter/widgets.dart';
import 'package:gloss_ui/gloss_ui.dart';

class ReadPickup extends StatelessWidget {
  const ReadPickup({super.key});
  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 440),
    child: SingleChildScrollView(
      child: const GlossDisclosure(
        title: 'Pickup instructions',
        child: Text('Collect your parcel at the front desk.'),
      ),
    ),
  );
}

Parameters

GlossDisclosure API ↗
title
What it is about.
child
What it opens to.
subtitle
A line under the title.

Controls whether the detail is expanded. Leave it unset for internal state.
initiallyExpanded
Whether it starts open, when it holds its own.
onChanged
Called with whether it is now open.
style
Its own style, over GlossThemeData.disclosureStyle.
