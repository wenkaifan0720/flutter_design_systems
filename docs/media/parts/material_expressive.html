Resize a missing cover

#

A route guide has no cover image. Switch between a wide and a square frame to see how the look draws its fallback at each size.

import 'package:flutter/widgets.dart';
import 'package:material_expressive_ui/material_expressive_ui.dart';

class ResizeCover extends StatefulWidget {
  const ResizeCover({super.key});
  @override
  State<ResizeCover> createState() => _ResizeCoverState();
}

class _ResizeCoverState extends State<ResizeCover> {
  bool square = false;
  @override
  Widget build(BuildContext context) {
    final aspect = square ? 1.0 : 16 / 9;
    return ConstrainedBox(
      constraints: const BoxConstraints(maxWidth: 440),
      child: SingleChildScrollView(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            SizedBox(
              width: 156,
              child: ExpressiveMedia(
                slotId: 'route-guide',
                aspectRatio: aspect,
                semanticLabel: 'Route guide cover',
              ),
            ),
            const SizedBox(height: 12),
            ExpressiveOutlinedButton(
              square ? 'Wide cover' : 'Square cover',
              onPressed: () => setState(() => square = !square),
            ),
          ],
        ),
      ),
    );
  }
}

Parameters

ExpressiveMedia API ↗
slotId
The declared media slot the picture resolves from.
aspectRatio
Sets the ratio of frame width to height.
fit
How the picture fills its box.
alignment
Positions the image inside its frame.
corner
The corner the box is rounded by, on the theme's corner scale.
placeholder
What stands in while the picture is pending or missing.
semanticLabel
Describes the picture independently of its fallback.
style
Stateful visual overrides for the image frame and fallback glyph.
shape
The library shape the picture is masked by (ExpressiveMedia.shaped).
