Resize a missing cover

#

A route guide has no cover image. Switch between a wide and a square frame to see how the look draws its fallback at each size.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class ResizeCover extends StatefulWidget {
  const ResizeCover({super.key});
  @override
  State<ResizeCover> createState() => _ResizeCoverState();
}

class _ResizeCoverState extends State<ResizeCover> {
  bool wide = true;

  @override
  Widget build(BuildContext context) => SingleChildScrollView(
    child: Column(
      mainAxisSize: MainAxisSize.min,
      spacing: 16,
      children: [
        CivicSegmentedControl<bool>(
          labelText: 'Frame',
          segments: const [
            CivicSegment(value: true, label: 'Wide cover'),
            CivicSegment(value: false, label: 'Square cover'),
          ],
          value: wide,
          onChanged: (next) => setState(() => wide = next),
        ),
        SizedBox(
          width: 200,
          child: CivicImage(
            image: null,
            description: 'Route guide cover',
            caption: 'Route guide',
            aspectRatio: wide ? 16 / 9 : 1,
          ),
        ),
      ],
    ),
  );
}

Parameters

CivicImage API ↗
image
The picture; null shows its place with missingLabel.
description
Says what the picture shows, for a screen reader.
caption
Words under the picture.
aspectRatio
The frame’s width over its height.
missingLabel
Said where the picture is missing.
