Open the details and dismiss the dialog to return to its trigger. Changing the theme closes the dialog so you can reopen it in the new palette.

import 'package:flutter/widgets.dart';
import 'package:fluent2_design_ui/fluent2_design_ui.dart';

class DraftDetails extends StatelessWidget {
  const DraftDetails({super.key});

  @override
  Widget build(BuildContext context) => Fluent2Button(
    'View draft details',
    appearance: Fluent2ButtonAppearance.primary,
    onPressed: () => showFluent2Dialog<void>(
      context,
      builder: (dialogContext) => Fluent2Dialog(
        title: 'Draft details',
        message: 'Only visible to you until you publish',
        actions: [
          Fluent2Button(
            'Done',
            appearance: Fluent2ButtonAppearance.primary,
            onPressed: () => Navigator.pop(dialogContext),
          ),
        ],
      ),
    ),
  );
}

Parameters

Fluent2Dialog API ↗
title
Heading that names the dialog.
message
Body text below the heading.
actions
Widgets in the action row.
style
Overrides the component’s themed appearance.
content
Places custom content below the heading.
