Choose a price range

#

Adjust each end of the price filter. The readout gives the lowest and highest prices in dollars.

Tab reaches each end in turn; the arrow keys move it a step.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class ChoosePriceRange extends StatefulWidget {
  const ChoosePriceRange({super.key});
  @override
  State<ChoosePriceRange> createState() => _ChoosePriceRangeState();
}

class _ChoosePriceRangeState extends State<ChoosePriceRange> {
  DesignRangeValues prices = const DesignRangeValues(40, 120);

  @override
  Widget build(BuildContext context) => CivicRangeSlider(
    labelText: 'Price',
    values: prices,
    max: 200,
    divisions: 20,
    valueLabel: (price) => '\$${price.round()}',
    onChanged: (next) => setState(() => prices = next),
  );
}

Parameters

CivicRangeSlider API ↗
values
The range, from its start to its end.
onChanged
Receives the range as either end moves.
min
The track’s start.
max
The track’s end.
divisions
How many steps the track has.
labelText
Asks for the range.
valueLabel
Says a value in words, at each end and to a screen reader.
