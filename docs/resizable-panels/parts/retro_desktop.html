Resize the panes

#

Drag the divider between Files and Notes, or focus it and use the horizontal arrow keys. Watch the two panes exchange space.

import 'package:flutter/widgets.dart';
import 'package:retro_desktop_ui/retro_desktop_ui.dart';

class ResizePanes extends StatelessWidget {
  const ResizePanes({super.key});
  @override
  Widget build(BuildContext context) => ConstrainedBox(
    constraints: const BoxConstraints(maxWidth: 640),
    child: const SizedBox(
      height: 140,
      child: RetroDesktopResizable(
        minFirst: 88,
        minSecond: 88,
        first: Center(child: Text('Files')),
        second: Center(child: Text('Notes')),
      ),
    ),
  );
}

Parameters

RetroDesktopResizable API ↗
second
The panes, start then end (or top then bottom).
axis
Which way they stand.
initialFraction
Where the bar starts, 0 to 1.
minSecond
The minimum extent of the second pane.
onChanged
Reports where the bar moved to.
label
The bar's name for a screen reader.
focusNode
Supplies a focus node owned and disposed by the caller.
autofocus
Whether the bar takes the focus when it first appears and nothing else has it.
first
The pane on the reading-start side.
minFirst
The minimum extent of the first pane.
