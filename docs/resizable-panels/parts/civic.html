Resize the panes

#

Drag the divider between Files and Notes, or focus it and use the horizontal arrow keys. Watch the two panes exchange space.

Tab reaches the divider; the left and right arrows move it. On a phone the panes stand one at a time, with a back link to the first.

import 'package:civic_ui/civic_ui.dart';
import 'package:flutter/widgets.dart';

class ResizePanes extends StatelessWidget {
  const ResizePanes({super.key});

  @override
  Widget build(BuildContext context) => SizedBox(
    height: 220,
    child: CivicSplitView(
      semanticLabel: 'Files and Notes',
      minFirst: 120,
      minSecond: 120,
      first: const Padding(padding: EdgeInsets.all(16), child: Text('Files')),
      second: const Padding(padding: EdgeInsets.all(16), child: Text('Notes')),
    ),
  );
}

Parameters

CivicSplitView API ↗
first
The pane at the start.
second
The pane at the end.
initialFraction
The share of the width the first pane starts with.
minFirst
The first pane’s least width.
minSecond
The second pane’s least width.
semanticLabel
Names the divider for a screen reader.
