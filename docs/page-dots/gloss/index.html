Page indicator dots

Page dots show a position within a short, fixed sequence. A nearby page name helps distinguish the destinations represented by the marks.

About this look Stint app Gloss on pub.dev ↗

The code and parameters below are Gloss's. This page in each look: Appliance, Brutal, Civic, Clay, Comic, Fluent 2, Frosted, Gloss, Keycap, Ledger, Material Expressive, Minimal, Neumorphism, Retro Desktop, Studio, Terminal, Material (Flutter), Cupertino (Flutter).

Browse three pages

#

Choose a dot to move between Cover, Notes and Credits. The selected mark follows the page title.

Flutter preview Open preview ↗
components/page-dots/gloss/browse_pages.dart
import 'package:flutter/widgets.dart';
import 'package:gloss_ui/gloss_ui.dart';

class BrowsePages extends StatefulWidget {
  const BrowsePages({super.key});
  @override
  State<BrowsePages> createState() => _BrowsePagesState();
}

class _BrowsePagesState extends State<BrowsePages> {
  int page = 0;
  static const titles = ['Cover', 'Notes', 'Credits'];

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      Text(titles[page]),
      const SizedBox(height: 12),
      GlossPageDots(
        pageCount: titles.length,
        page: page,
        onPageChanged: (next) => setState(() => page = next),
      ),
    ],
  );
}

Parameters

GlossPageDots API ↗
pageCount
Total number of pages.
page
Zero-based position of the current page.
onPageChanged
Receives the position requested by a dot.

Shared behaviour

  • Keyboard and focus. Focus the dot controls, move to another position and activate it. Follow the page title to check which position opened.
  • Screen readers. Inspect the page labels and selected state, then read the current page title.
  • Direction and type. Switch to RTL to inspect the first and last dots. In larger type, compare the fixed marks with the page title.
