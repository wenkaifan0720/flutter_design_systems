Confirm a save

#

Press Save draft twice. Each confirmation includes its revision number, so you can see whether this look stacks, queues or replaces a message.

components/toast/material/confirm_save.dart
import 'package:material_ui/material_ui.dart';

class ConfirmSave extends StatefulWidget {
  const ConfirmSave({super.key});
  @override
  State<ConfirmSave> createState() => _ConfirmSaveState();
}

class _ConfirmSaveState extends State<ConfirmSave> {
  int revision = 0;

  @override
  Widget build(BuildContext context) => Scaffold(
    body: Center(
      child: FilledButton(
        onPressed: () => ScaffoldMessenger.of(
          context,
        ).showSnackBar(SnackBar(content: Text('Revision ${++revision} saved'))),
        child: const Text('Save draft'),
      ),
    ),
  );
}

Parameters

SnackBar API ↗
content
The message, usually a Text; ScaffoldMessenger.showSnackBar shows it and queues the next.
action
One SnackBarAction, such as Undo.
duration
How long it stays.
behavior
Whether it spans the bottom edge or floats above it.
showCloseIcon
Whether it shows a close button.
