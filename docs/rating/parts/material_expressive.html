Rate a guide

#

Choose a rating for the guide and read the score out of five.

Tab to a star and press Enter or Space to set the score.

import 'package:flutter/widgets.dart';
import 'package:material_expressive_ui/material_expressive_ui.dart';

class RateGuide extends StatefulWidget {
  const RateGuide({super.key});
  @override
  State<RateGuide> createState() => _RateGuideState();
}

class _RateGuideState extends State<RateGuide> {
  int score = 3;

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      ExpressiveRating(
        semanticLabel: 'Rate the guide',
        value: score.toDouble(),
        onChanged: (next) => setState(() => score = next),
      ),
      const SizedBox(height: 12),
      Text('Rated $score out of 5'),
    ],
  );
}

Parameters

ExpressiveRating API ↗
value
Score currently shown by the marks.
semanticLabel
Names the read-only rating. The interactive stars use their individual labels.
onChanged
Receives the new score.
