Inspect a file

#

Open File details, read the owner and last edit, then close the panel. Switch to RTL and open it again to see which edge it uses.

components/side-sheet/ledger/inspect_file.dart
import 'package:flutter/widgets.dart';
import 'package:ledger_ui/ledger_ui.dart';

class InspectFile extends StatelessWidget {
  const InspectFile({super.key});

  @override
  Widget build(BuildContext context) => LedgerButton(
    'File details',
    onPressed: () => showLedgerSideSheet<void>(
      context,
      title: 'File details',
      builder: (_) => const Text('Owner: Mara Chen\nLast edited: 14 June'),
    ),
  );
}

Parameters

showLedgerSideSheet API ↗
title
Heading at the top of the panel.
builder
Builds the content inside the sheet.
width
Requested width of the open panel.
edge
Places the panel at the reading start or end.
