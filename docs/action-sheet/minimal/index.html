Action sheet

An action sheet gathers a few operations on one item. Include a way to dismiss it without making a choice.

About this look Stint app Minimal on pub.dev ↗

The code and parameters below are Minimal's. This page in each look: Appliance, Brutal, Civic, Clay, Comic, Fluent 2, Frosted, Gloss, Keycap, Ledger, Material Expressive, Minimal, Neumorphism, Retro Desktop, Studio, Terminal, Material (Flutter), Cupertino (Flutter).

Choose a file action

#

Open File actions and choose Pin or Unpin. The page shows the result after the sheet closes. Reopen it and cancel to keep the current state.

Press Tab to focus an action, then press Enter or Space to choose it.

Flutter preview Open preview ↗
components/action-sheet/minimal/file_actions.dart
import 'package:flutter/widgets.dart';
import 'package:minimal_ui/minimal_ui.dart';

class FileActions extends StatefulWidget {
  const FileActions({super.key});
  @override
  State<FileActions> createState() => _FileActionsState();
}

class _FileActionsState extends State<FileActions> {
  bool pinned = false;

  @override
  Widget build(BuildContext context) => Column(
    mainAxisSize: MainAxisSize.min,
    children: [
      MinimalButton(
        'File actions',
        onPressed: () => showMinimalActionSheet(
          context,
          title: 'File actions',
          actions: [
            MinimalActionSheetAction(
              'Pin',
              onPressed: () => setState(() => pinned = true),
            ),
            MinimalActionSheetAction(
              'Unpin',
              onPressed: () => setState(() => pinned = false),
            ),
          ],
        ),
      ),
      const SizedBox(height: 12),
      Text(pinned ? 'Pinned' : 'Unpinned'),
    ],
  );
}

Parameters

showMinimalActionSheet API ↗
title
Names the item or set of actions.
actions
Lists the choices in reading order.
message
Optional explanation above the choices.

Shared behaviour

  • Keyboard and focus. Tab to the opener and press Enter. Move through the choices with Tab and activate one, or dismiss the sheet with Escape.
  • Screen readers. The file actions have visible names. After the sheet closes, read the current pin state below the opener.
  • Direction and type. Labels follow the page direction and text scale. Check both actions and Cancel at the narrow width.
