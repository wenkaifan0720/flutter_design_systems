# Time picker

A time picker sets the hour and minute of a recurring event. A date is unnecessary when the reminder repeats every day.

## Set a reminder time

Move the reminder from 09:30 to another time. Some looks present the hour and minute inline, while others open a picker from the displayed time.

## Shared behaviour

- **Keyboard and focus.** Focus the hour or minute control and change its value. Use any confirmation action offered by the picker to apply the new time.
- **Screen readers.** Inspect the names of the hour and minute controls and read the reminder’s time below them.
- **Direction and type.** In RTL, check the order of the controls and read the time as a single value. Scroll inside the preview when larger type needs more height.
