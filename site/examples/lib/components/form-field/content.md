# Form field

A form field puts a label, instructions and validation beside one input. Keep the instructions close enough to read while correcting an entry.

## Name a project

Type a one-letter project name to see the validation message. Add a second letter to clear it.

## Shared behaviour

- **Keyboard and focus.** Tab into the name field, type and edit without leaving the field. Focus stays with the entry as the validation message changes.
- **Screen readers.** Read the label and help, then inspect the message after entering one letter.
- **Direction and type.** Check how the help and validation text wrap at phone width and 200% text. Switch to RTL to find the start of the field.
