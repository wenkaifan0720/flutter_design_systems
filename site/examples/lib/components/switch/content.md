# Switch

A switch changes a setting immediately. Use a label that names the setting and keep it stable when the value changes.

## Set reminders

Turn reminders on, then off. The message below the switch shows the current setting.

## Shared behaviour

- **Keyboard and focus.** Tab to the switch and press Space. The same control turns the setting back off.
- **Screen readers.** Read the Reminders label and the current state. The message after the switch spells out the resulting setting.
- **Direction and type.** Compare where the thumb rests in LTR and RTL. The message can wrap when the text size increases.
