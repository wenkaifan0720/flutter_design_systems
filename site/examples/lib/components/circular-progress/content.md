# Circular progress

A circular indicator fits a wait in a small space. Use an indeterminate spinner when a task is running and its completion time is unknown.

## Sync a folder

Start the folder sync. The example keeps it running until you choose Finish sync, so you can inspect the spinner at either text size.

## Shared behaviour

- **Keyboard and focus.** Tab to Start sync and press Enter or Space. Activate Finish sync to complete the example.
- **Screen readers.** Read the current sync status and the button label. Compare how each look names the indicator while it runs.
- **Direction and type.** The short status sits beside or below the indicator according to the look. Try RTL and large type at phone width.
