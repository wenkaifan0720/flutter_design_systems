# Menu bar

A menu bar groups commands by purpose on a desktop screen. Give each menu a short name and each command a verb.

## Run an editing command

Open Edit and choose Mark reviewed. Reopen Edit and choose Clear review to restore the draft.

## Shared behaviour

- **Keyboard and focus.** Tab to Edit and open its menu. Move to a command, press Enter to run it or Escape to dismiss the menu.
- **Screen readers.** Read the menu name, then the commands available while it is open. The note’s status records the result.
- **Direction and type.** In RTL, inspect where the menu opens relative to Edit. Try both commands with larger text in the phone frame.
