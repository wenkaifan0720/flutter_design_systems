# Media with fallback

A media frame reserves space for a picture while it is unavailable. Give the image a meaningful description and choose a shape that suits the content.

## Resize a missing cover

A route guide has no cover image. Switch between a wide and a square frame to see how the look draws its fallback at each size.

## Shared behaviour

- **Keyboard and focus.** Tab to Square cover or Wide cover and activate it to change the frame.
- **Screen readers.** Read the missing cover’s description and the resize action. The description stays the same when the shape changes.
- **Direction and type.** The empty image slot keeps its proportions in either direction. Its label and the resize action use the selected text size.
