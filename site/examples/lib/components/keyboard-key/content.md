# Keyboard key

A keyboard key label shows which key runs a command. Place it beside the name of the command, within the part of the interface where the shortcut works.

## Reset a counter

Activate Count one a few times. With focus still in the example, press Escape to reset the count.

## Shared behaviour

- **Keyboard and focus.** Tab to Count one and use Enter or Space to increment. The displayed key is a hint. Its Escape shortcut works while the button holds focus.
- **Screen readers.** Read the key label together with “Reset count”. The count appears after the hint.
- **Direction and type.** The key and its description follow reading order and can wrap at larger text sizes.
