# Timeline

A timeline puts events in time order. Write down what happened and when, so the sequence makes sense without the connecting line.

## Track a parcel

Read the packing event, then record delivery. A second dated entry appears. Reset the example to return to the first event.

## Shared behaviour

- **Keyboard and focus.** Tab to Record delivery and activate it. The dated entries can be read without stopping on each marker.
- **Screen readers.** Read the time and description for each event, then compare the list after recording delivery.
- **Direction and type.** The events stay in chronological order in RTL. At larger text sizes, check how each description lines up with its time.
