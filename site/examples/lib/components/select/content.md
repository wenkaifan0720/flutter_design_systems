# Select

Use a select for one answer from a fixed list. Name the field for the decision and each option for the value that will be kept.

## Choose a paper size

Open Paper size and choose A5 or Letter. The print summary reflects the committed choice.

## Shared behaviour

- **Keyboard and focus.** Tab to the select and open its list. Use the arrows and Enter to choose, or Escape to leave the previous value in place.
- **Screen readers.** Listen for the field name and current value. In the list, each paper size has a distinct name.
- **Direction and type.** The menu inherits the preview direction and text scale. Try opening it in the narrow frame at 200%.
