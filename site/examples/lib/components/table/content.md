# Table

Use a table to compare the same facts across several items. Short column labels help readers move between a value and the item it belongs to.

## Compare costs

Compare the two costs. Switch between one and two orders and check how both amounts change.

## Shared behaviour

- **Keyboard and focus.** Tab to the quantity action to change the figures. Reading the cells takes no keyboard activation.
- **Screen readers.** Read each item with its amount. Look for the same association after changing the quantity.
- **Direction and type.** Compare the wide columns with the phone layout, then switch direction. Larger type may wrap labels or make a table scroll.
