# Button

A button runs an action on the current screen. Give it a verb that tells the reader what will happen. Use a link to take someone to another destination.

## Save a draft

Save the draft, then reset the example to try the action again.

## Shared behaviour

- **Keyboard and focus.** Tab moves focus to an enabled button. Enter or Space activates it. A disabled action leaves the focus order.
- **Screen readers.** The button exposes its label, role and enabled state. The visible label changes when the draft is saved.
- **Direction and type.** The actions follow reading order in RTL. At larger text sizes they can wrap onto separate lines.
