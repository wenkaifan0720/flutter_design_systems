# Pull to refresh

Pull to refresh asks for a new version of an existing list. Keep the last result visible while the update runs so the reader can tell what changed.

## Update the board

Pull down from the top of the board, or press Refresh. A completed update advances the issue number.

## Shared behaviour

- **Keyboard and focus.** Tab to Refresh and activate it to request the same update as a pull. The button is unavailable while that update runs.
- **Screen readers.** Look for the refresh action on the list. After either trigger, read the new issue number in the first row.
- **Direction and type.** Try the gesture in RTL. It still starts at the top, and the issue label uses the selected text size.
