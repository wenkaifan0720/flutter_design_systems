# Multi-select

A multi-select keeps several answers in a single field. Use it for a growing list of labels when people need to see and remove the choices they have made.

## Tag a draft

Add Home or Travel to the draft, then remove a label and read the updated list below.

## Shared behaviour

- **Keyboard and focus.** Tab to the field, type to narrow the options and use the keyboard to choose a match. The field’s selected labels can also be removed.
- **Screen readers.** Read the names of the selected labels and the available choices. The summary lists the labels still attached to the draft.
- **Direction and type.** Add all three labels on a narrow frame and switch direction. Try larger text to see how the selected labels share the space.
