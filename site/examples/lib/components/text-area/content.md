# Text area

Use a text area for a note that can span several lines. Give people room to see the surrounding sentences while they edit.

## Write a note

Write a delivery note. Press Enter to add another line and watch the line count change.

## Shared behaviour

- **Keyboard and focus.** Tab into the note. Enter inserts a line break, and the arrow keys move the caret through the text.
- **Screen readers.** The editable field has the name “Delivery note”. The count below it includes the lines separated by Enter.
- **Direction and type.** The field uses the available width. Lines can wrap as the frame narrows or the type grows without changing the count.
