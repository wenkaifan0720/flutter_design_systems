# Skeleton

A skeleton reserves space for content that is still loading. Match the placeholder to what will appear there and give the wait a visible name.

## Load file details

Read the loading state, then choose Show details. The placeholder gives way to a file name and its owner. Choose Reload to try again.

## Shared behaviour

- **Keyboard and focus.** The skeleton requires no keyboard interaction. Tab to the button to switch between the loading state and the file.
- **Screen readers.** The example names the wait and supplies real text when it finishes. Read both states and check what the look announces for the placeholder.
- **Direction and type.** The file text follows the page direction and can wrap at larger sizes. The placeholder stands in the same content area.
