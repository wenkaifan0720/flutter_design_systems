# Banner

A banner keeps a message in the page while it still matters. Use one when a condition affects the reader’s next action, such as editing a draft offline.

## Show a connection change

Choose Go offline. Read what will happen to your changes, then reconnect to clear the message.

## Shared behaviour

- **Keyboard and focus.** Tab to Go offline and activate it. The same control lets you reconnect when the banner is visible.
- **Screen readers.** Read the banner heading and the explanation together. The button’s name changes with the connection state.
- **Direction and type.** The heading and explanation follow reading direction. At larger type the message can occupy several lines.
