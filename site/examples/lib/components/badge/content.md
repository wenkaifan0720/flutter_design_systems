# Count badge

A count badge adds a short quantity to a named item. Keep the thing being counted close enough that the number has a meaning.

## Read messages

Begin with three unread messages. Mark one read to see the count fall, then reset the inbox when it is empty.

## Shared behaviour

- **Keyboard and focus.** Tab to Mark one read and activate it repeatedly. Reset inbox restores the three messages.
- **Screen readers.** Read the inbox name, then its unread count. Look-specific badges can hide the mark at zero.
- **Direction and type.** The count stays with the inbox in RTL. Check the badge and its action at both text sizes.
