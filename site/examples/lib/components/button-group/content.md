# Button group

Group a few commands that operate on the same thing. A toolbar suits repeated actions such as changing the zoom of a document.

## Adjust zoom

Use Out or In to change the zoom by ten percentage points. The current value appears below the controls.

## Shared behaviour

- **Keyboard and focus.** Use Tab to reach the group. Depending on the look, move between its controls with Tab or the horizontal arrows, then activate the desired command.
- **Screen readers.** The commands have separate names. Read the percentage below the group to check the result.
- **Direction and type.** The pair follows reading order. Try the phone preview at 200% to see how each command fits its button.
