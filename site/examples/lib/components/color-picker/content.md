# Color picker

A colour picker combines related controls for choosing a colour. Show its numeric value so readers can identify or reproduce the chosen shade.

## Choose an ink colour

Change the hue and then adjust the colour. The hexadecimal readout shows the red, green and blue channels of the new ink.

## Shared behaviour

- **Keyboard and focus.** Tab between the picker’s adjustable controls. Use the arrows on the focused control and inspect the hexadecimal result.
- **Screen readers.** Read the names and values of the colour controls and the ink code beneath the picker.
- **Direction and type.** Try the picker in RTL and at 200% text. The hexadecimal value keeps its written order.
