# Side sheet

A side sheet keeps details about the current item beside the page. Give the panel a heading so it is clear which item the details describe.

## Inspect a file

Open File details, read the owner and last edit, then close the panel. Switch to RTL and open it again to see which edge it uses.

## Shared behaviour

- **Keyboard and focus.** Activate the opener with Enter. Tab through the panel and dismiss it with its close action or Escape.
- **Screen readers.** Read the heading, owner and last edit inside the panel. After dismissal, check where focus returns.
- **Direction and type.** The panel opens from the reading end by default. Try the phone width with larger text to see how much room the details take.
