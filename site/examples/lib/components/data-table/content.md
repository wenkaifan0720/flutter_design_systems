# Data table

Use a data table when readers need to work with the records they are comparing. Sorting a numeric column should order its values by size.

## Sort the stock list

Sort by Units to put the smallest quantity first, then reverse the order. Select a row or move to the next page to inspect the remaining record.

## Shared behaviour

- **Keyboard and focus.** Tab through the sortable headers and use Enter or Space. Try the row and paging controls in the order the look supplies.
- **Screen readers.** Read the header’s sort state, then follow the first item and its quantity. Compare the announced row state before and after selection.
- **Direction and type.** RTL changes where each column starts. Try sorting at phone width and 200% to check how headers and values fit.
