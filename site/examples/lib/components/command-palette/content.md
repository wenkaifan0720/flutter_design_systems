# Command palette

A command palette makes actions searchable by name. It helps people reach commands without remembering which menu contains them.

## Find a note command

Open Commands and search for Review. Run Review note to change the note’s status. The Reset note command restores the draft.

## Shared behaviour

- **Keyboard and focus.** Activate Commands and type a few letters. Use the arrows to highlight a match, Enter to run it, and Escape to return without choosing.
- **Screen readers.** Inspect the search field, matching command names and focused result. Read the note’s status after the palette closes.
- **Direction and type.** Try the open palette in RTL at phone width. At 200% text, check both the search field and the matching action.
