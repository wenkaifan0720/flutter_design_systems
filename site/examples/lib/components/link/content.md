# Link

Use a link when its words name a place the reader can visit. A specific destination makes sense even when read out of the surrounding paragraph.

## Read the guide

Follow Reading guide to its own screen. Use Back to library to return and follow the link again.

## Shared behaviour

- **Keyboard and focus.** Tab to the link and press Enter. The destination has its own return link.
- **Screen readers.** Read the destination name before following the link. At the destination, the guide text comes before the way back.
- **Direction and type.** Both screens keep the selected reading direction and text size. The destination text can wrap in the narrow frame.
