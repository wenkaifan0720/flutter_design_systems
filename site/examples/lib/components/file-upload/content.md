# File upload

A file input lets someone select a document from their device. Use a label that says what the attachment is for.

## Attach a file

Choose a local file. Its name appears in the preview. The example reads only the file’s name and size and keeps the selection in this browser tab.

## Shared behaviour

- **Keyboard and focus.** Tab to the choose action and activate it. The system file chooser handles keyboard navigation until you pick a file or cancel.
- **Screen readers.** Read the attachment label before opening the chooser, then locate the selected file name in the example.
- **Direction and type.** Try a long file name at phone width and 200% text. Its letters keep their own order when the surrounding layout switches to RTL.
