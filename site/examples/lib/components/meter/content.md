# Meter

A meter compares a current amount with a known limit. It can stay at the same value until the thing being measured changes.

## Check room capacity

The room holds eight people. Add two at a time and watch the level and count change. Reset the room when all eight places are taken.

## Shared behaviour

- **Keyboard and focus.** Tab to Add two people. Activate it to change the measured amount. The meter itself is a readout.
- **Screen readers.** Read the count after each change. The separate text gives the units and the capacity alongside the look’s own meter semantics.
- **Direction and type.** Try the compact readout with the page set to RTL and larger type.
