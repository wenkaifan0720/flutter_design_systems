# Input group

Use an input group for an editable value with a fixed unit or other context beside it. Include the unit in the field name so people can enter the right value by ear.

## Weigh a parcel

Enter the weight of a parcel. The kilogram unit stays in place when you edit the number or clear the field.

## Shared behaviour

- **Keyboard and focus.** Tab into the field and edit the number. The unit is fixed text and has no separate action.
- **Screen readers.** The field name includes “kilograms”. The summary below repeats the entered amount with its unit.
- **Direction and type.** Watch the unit beside the field in RTL. At large text sizes the field and the summary still share the width of the phone frame.
