# Tabs

Tabs switch between related sections of the same view. Keep their names short and their order stable. Use a segmented control for choosing a value in a form.

## Switch sections

Select Overview or Activity to change the content below the tab bar.

## Shared behaviour

- **Keyboard and focus.** Tab reaches the bar. In looks that use `RawTabBar`, one tab stop serves the bar and the horizontal arrows move selection in reading order.
- **Screen readers.** Each tab exposes its label and selected state. Read past the bar to reach the current section’s content.
- **Direction and type.** RTL reverses the horizontal direction. Labels inherit the text scale, so both directions can be tried with larger type.
