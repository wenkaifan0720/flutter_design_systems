# Search field

Use a search field to narrow a collection by the words someone remembers. Keep the matches close to the query so it is clear what changed.

## Find a title

Type “field” to find two titles, then “travel” to find one. Delete the query to see all three again.

## Shared behaviour

- **Keyboard and focus.** Tab to search. If the look shows a search entry, activate it to reach the editor, then type. The list filters as you edit, so you can keep your place in the field.
- **Screen readers.** Read past the editable query to reach the matching titles. A query with no matches shows an explicit empty result.
- **Direction and type.** Try RTL and large text to inspect the search affordance and the wrapping titles.
