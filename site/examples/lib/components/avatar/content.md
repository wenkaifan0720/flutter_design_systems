# Avatar

An avatar identifies a person in a small space. Initials give the reader a recognizable fallback when a photo is unavailable.

## Switch reviewers

Switch between Ana Lee and Jo Ray. Compare the initials on the avatar with the full name beneath it.

## Shared behaviour

- **Keyboard and focus.** Tab to Switch reviewer to change the person. The identity marker itself takes no action.
- **Screen readers.** Read the full name and compare it with the name the avatar exposes. The caption changes with the initials.
- **Direction and type.** Initials stay in their usual order in RTL. Try 200% and compare the compact face with the full-size name.
