# List row

Use a list row for one item in a collection. A short title identifies the item and a second line can carry its status.

## Read a message

Activate the message row to mark it read. Activate it again to return it to Unread.

## Shared behaviour

- **Keyboard and focus.** Tab to the row and activate it. The entire row handles the action.
- **Screen readers.** Read the message title and its current status before and after activation.
- **Direction and type.** The title and status share a leading edge. Compare their positions in LTR and RTL at larger type.
