# Icon button

An icon button puts a familiar action in a toolbar or beside an item. Choose a symbol people recognise and give it a name that describes the action.

## Add a day

Activate the plus to extend a loan by one day. The number below it shows the new loan period.

## Shared behaviour

- **Keyboard and focus.** Tab to the plus and activate it with Enter or Space. You can press it again without leaving the control.
- **Screen readers.** The action is named “Add a day”. Read the text below it for the current loan period.
- **Direction and type.** The plus keeps its meaning in either direction. Its spoken name stays available even when the control shows just the icon.
