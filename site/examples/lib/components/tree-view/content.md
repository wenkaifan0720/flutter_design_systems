# Tree view

A tree lets readers explore a hierarchy without leaving the current view. Use short, distinct names so a reader can follow the path back to a parent.

## Browse folders

Expand Files to reveal Notes and Maps. Move to Maps, then return to Files and close the branch.

## Shared behaviour

- **Keyboard and focus.** Tab into the tree. Use the horizontal arrows to open or close a branch and Up or Down to move between visible rows.
- **Screen readers.** Read the folder names and their expanded states. After closing Files, its children leave the reading order.
- **Direction and type.** In RTL the arrow toward a child changes direction. Try the tree at the larger text setting and compare the indentation at each level.
