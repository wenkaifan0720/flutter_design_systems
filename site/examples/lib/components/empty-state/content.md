# Empty state

An empty state explains what belongs in a collection before its first item appears. When there is a natural first step, put that action beside the explanation.

## Start a reading list

Add the first book. It replaces the empty state. Remove it to see the original invitation again.

## Shared behaviour

- **Keyboard and focus.** Tab to Add book and activate it. In the populated view, use Remove book to return to the empty list.
- **Screen readers.** Read the empty heading and its action. After adding the book, read the title that replaces the invitation.
- **Direction and type.** The heading, explanation and action follow the reading direction. Try them at phone width and 200% text.
