# Navigation drawer

A navigation drawer or sidebar gives destinations room for a full label. A persistent sidebar is useful when a wide layout has space beside the current page.

## Choose from a sidebar

Choose Home or Search from the open panel. The current page is printed below it.

## Shared behaviour

- **Keyboard and focus.** Tab into the panel and follow the focus indicator to a destination. Activate it to change the page.
- **Screen readers.** Read the destination names and inspect which is selected. Continue past the panel for the current page.
- **Direction and type.** Switch to RTL to move the panel to the reading start. At larger type, inspect each destination’s label in the open panel.
