# App shell

An app shell holds the current page and its main navigation together. Use the look’s scaffold to give related pages a consistent place to live.

## Navigate a workspace

Choose Search, then switch between phone and desktop. Observe where the look places navigation and whether the current page stays selected.

## Shared behaviour

- **Keyboard and focus.** Tab to a destination and activate it. The current page stays in the same shell while the content changes.
- **Screen readers.** Read the destinations and their selected state, then locate the content of the current page.
- **Direction and type.** Compare where navigation sits at phone and desktop widths. Try larger text and RTL while Search is selected.
