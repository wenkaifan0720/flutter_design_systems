# Text field

Use a text field for a short, single-line answer such as the name of a draft. A visible label still identifies the field after someone starts typing.

## Name a draft

Type a title, then edit or erase it. The draft heading below follows your changes and returns to Untitled when the field is empty.

## Shared behaviour

- **Keyboard and focus.** Tab to the field and type. Use the arrows to move the caret and the usual editing shortcuts to select or replace text.
- **Screen readers.** The field is named “Draft title”. Its editable value and the resulting heading can be read separately.
- **Direction and type.** The label and the heading follow reading direction. Try a long title at 200% to see the heading wrap.
