# Resizable panels

A split view lets a reader trade space between two related panes. Keep a useful minimum width for each pane when the divider moves.

## Resize the panes

Drag the divider between Files and Notes, or focus it and use the horizontal arrow keys. Watch the two panes exchange space.

## Shared behaviour

- **Keyboard and focus.** Tab to the divider and use Left or Right to adjust it. Enter collapses the first pane and restores it on a second press.
- **Screen readers.** Inspect the divider’s adjustable value. Move it and read the new position, then read the labels in both panes.
- **Direction and type.** In RTL the first pane begins on the right. At phone width and larger type, try the minimum width on each side.
