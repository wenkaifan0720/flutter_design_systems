# Breadcrumbs

Breadcrumbs show where a page sits within a hierarchy. Each ancestor leads back to a broader view and the last crumb names the current location.

## Go up to a parent folder

From Drafts, choose Files to return to its parent folder. Open Drafts again to restore the trail.

## Shared behaviour

- **Keyboard and focus.** Tab to an ancestor and activate it. Once at Files, use Open Drafts to return.
- **Screen readers.** Read the path in order, then inspect which crumbs are links and which identify the current location.
- **Direction and type.** Compare the order and separators in RTL. At 200% text, try both the full trail and its shorter parent view.
