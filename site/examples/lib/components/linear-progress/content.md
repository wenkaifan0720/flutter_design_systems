# Linear progress

A linear progress indicator shows how far a task has advanced. Use a determinate value when you know how much work is left.

## Track four uploads

One of four files has finished. Complete another file to advance the indicator by a quarter. Start over after the fourth.

## Shared behaviour

- **Keyboard and focus.** Tab to Complete next file and activate it repeatedly. The progress display itself does not need to be operated.
- **Screen readers.** Read the completed file count after each activation. Compare it with the value exposed by the indicator.
- **Direction and type.** Try RTL to inspect the fill direction and larger type to see the count above the control.
