# Hover card

A hover card offers a quick look at a linked item. Put the full information at the link destination so touch and keyboard readers can reach it as well.

## Preview a file owner

Rest the pointer on Mara Chen to preview her role. Activate her name to read the same detail in the page.

## Shared behaviour

- **Keyboard and focus.** Tab to the name and press Enter to open the profile. Moving the pointer away dismisses the hover preview.
- **Screen readers.** Read the name, activate it, then read the profile below. Some looks intentionally omit the hover copy from the accessibility tree.
- **Direction and type.** The profile text follows the page direction and wraps at large type. Check the floating copy at phone width too.
