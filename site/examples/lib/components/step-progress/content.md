# Step progress

A step indicator shows progress through a short, predictable sequence. Use step names that describe what the reader does at each stage.

## Review an order

Start at Cart, continue to Address and Review, then start again. The current step and its name change together.

## Shared behaviour

- **Keyboard and focus.** Tab to Continue and activate it to advance. At Review the same action becomes Start again.
- **Screen readers.** Read the indicator and the current step’s name. The action below it identifies what happens next.
- **Direction and type.** In RTL, inspect the sequence from the reading start. At 200% text compare the step labels with the current-step readout.
