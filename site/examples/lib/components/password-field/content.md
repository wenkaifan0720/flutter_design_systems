# Password field

Use a password field when the reader needs to enter a secret and briefly check their typing. The reveal action lets them make that choice.

## Check your typing

Type a sample word, reveal it, then conceal it again. The message below confirms that the field contains text.

## Shared behaviour

- **Keyboard and focus.** Type in the field, then use Tab to reach the reveal action. Activate it again to conceal the word.
- **Screen readers.** The field has a password label and the reveal control has its own action name. Read the confirmation below without repeating the sample word.
- **Direction and type.** The field and its reveal action share the available width. Try the narrow frame with RTL and larger type.
