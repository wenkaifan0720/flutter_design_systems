# Avatar group

An avatar group shows who is involved when space is limited. Keep the full membership available when the group can show only a few faces.

## Invite a reviewer

Start with Ana and Jo. Invite Kim to see how the look fits a third reviewer, then remove Kim.

## Shared behaviour

- **Keyboard and focus.** Use Tab to reach Invite Kim, then activate the same control to remove the invitation.
- **Screen readers.** Compare the group’s name or count with the names listed beneath it. The list includes everyone, including anyone represented by an overflow count.
- **Direction and type.** Check which edge holds the overflow count in RTL. The written names can wrap at larger text sizes.
