# Status view

A status view explains what happened to a whole region of a page. When the reader can recover, put an action beside the explanation.

## Retry a file list

The file list could not load. Retry to see the recovered item, then reset the example to return to the error.

## Shared behaviour

- **Keyboard and focus.** Tab to the retry action and activate it. The recovered list includes a reset action.
- **Screen readers.** Read the failure heading, the reason and the retry action in order. After retrying, read the item that replaced them.
- **Direction and type.** The message follows reading direction and can occupy more lines at larger text sizes.
