# Description list

A description list pairs each label with a value for one record. Use it when readers need to look up individual facts about the same thing.

## Inspect a booking

Check the room and day for the first booking. Switch bookings and read the same two labels with their new values.

## Shared behaviour

- **Keyboard and focus.** Tab to the booking switch and activate it. The individual facts are available in reading order.
- **Screen readers.** Read Room with its name, then Day with its value. Those pairings stay intact when you switch records.
- **Direction and type.** Compare where the label and value sit in RTL and at 200%. A value can move beneath its label in a narrow layout.
