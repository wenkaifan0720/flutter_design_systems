# Menu

A menu keeps related commands together until they are needed. Group options under a trigger whose name tells readers what they can change.

## Choose a sort order

Open Sort files and choose Date. The current order appears below the trigger. Reopen the menu and choose Name to switch back.

## Shared behaviour

- **Keyboard and focus.** Open the menu with Enter. Use the arrow keys or Tab to reach a choice and activate it. Try Escape to dismiss without choosing.
- **Screen readers.** Read the two named options, then read the new sort order beneath the trigger.
- **Direction and type.** Menu labels use the surrounding direction and text size. On a narrow screen check the placement relative to the trigger.
