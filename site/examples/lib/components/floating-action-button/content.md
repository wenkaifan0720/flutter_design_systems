# Floating action button

A floating action button keeps one frequent action within reach over a view. Choose the action that creates or starts the main item on that screen.

## Create a note

Add a note using the floating plus at the lower end of the preview. The count at the top changes each time.

## Shared behaviour

- **Keyboard and focus.** Tab to the creation action and activate it. Focus stays on the button for the next note.
- **Screen readers.** The plus has the name “Add note”. The count is separate text at the start of the view.
- **Direction and type.** The button sits at the lower right in LTR and the lower left in RTL. Try larger type to see the space around its label.
