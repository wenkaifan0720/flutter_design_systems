# Combobox

Use a combobox to choose a known item from a list that is easier to search than to scan. Keep the text being edited distinct from the choice that has been accepted.

## Find a city

Type “Li” and choose Lisbon or Lima. The destination below the field changes when you accept a suggestion.

## Shared behaviour

- **Keyboard and focus.** Tab to the editable field. Type to filter, move through suggestions with the arrows and press Enter to choose. Try Escape with the list open.
- **Screen readers.** Listen for the editable query and the available options. Read the destination below the field for the committed city.
- **Direction and type.** The list opens beside the field in the current direction. Try larger type in the phone frame with the suggestions open.
